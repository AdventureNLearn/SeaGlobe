# StarFire records (dated snapshot)

Point records from a single dated snapshot of the public StarFire archive (StarFire by @wntrslmbr). The shipped records are in `starfire.json`. Pins are coarse (0.1 degree). The layer is historical only; there is no live feed and no refresh URL. Reports without coordinates are omitted. Article text and personal data are not stored; each record keeps its own source citation where the archive gave one. This layer is separate from the official declassified UAP layer.
